# 💪 FitLog

### Track Workouts, Build Your Plan & Stay Consistent

FitLog is a modern fitness-focused web application that helps users explore workouts, create a daily workout plan, save exercises, and track basic workout statistics. It provides a clean and responsive interface designed to make workout planning simple and enjoyable.

🔗 **Live Website:** https://fitlog-mocha.vercel.app/

---

## ✨ Features

### 🏋️ 1. Explore Workouts

Browse through a collection of workouts and exercises with useful information such as equipment, duration, calories burned, and ratings.

### 📋 2. Create a Workout Plan

Add exercises to your daily workout plan and organize the workouts you want to complete.

### 💾 3. Save Workouts

Save your favorite workouts for quick access later and keep them separate from your daily workout plan.

### 📊 4. Workout Statistics

View useful statistics including the number of exercises, total workout duration, and estimated calories for your current plan or saved workouts.

### ✅ 5. Mark Workouts as Done

Track completed exercises and manage your workout routine more effectively.

### 🗑️ 6. Remove Workouts

Easily remove exercises from your workout plan with instant toast notifications.

### 📱 7. Responsive Design

FitLog provides a clean and modern responsive interface that works smoothly across desktop, tablet, and mobile devices.

### ❌ 8. Custom Not Found Page

Includes a custom fitness-themed 404 page for invalid workout routes.

## 📸 Project Overview

FitLog is designed with a modern dark fitness-inspired interface with a bright lime accent color.

The application includes dedicated sections for browsing workouts, viewing workout details, creating a workout plan, and managing saved exercises.

---

## 🎯 Purpose

The goal of FitLog is to provide a simple and user-friendly platform for discovering workouts and organizing daily fitness routines while practicing modern web development technologies.
